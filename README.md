# **_SIMULADOR VOLTPLAY - FÍSICA TEÓRICA III_**

É um simulador criado por um grupo de estudantes da Universidade Federal do Vale do São Francisco, composto por alunos de Engenharia Civil e Engenharia de Computação, destinado a aplicar os conhecimentos de Física Teórica III na prática de vários conceitos ligados à física eletromagnetica.

## CONCEITOS APLICADOS:

1. Lógica Vetorial;
2. Conceitos de Campo Magnético;
3. Lei da força de Lorentz;

## LINGUAGENS UTILIZADAS:

1. Linguagem de Programação (JAVA);
2. Bibliotecas:
   1. JavaFX;
